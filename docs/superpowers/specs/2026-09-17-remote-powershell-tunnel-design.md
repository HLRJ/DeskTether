# DeskTether V0.2 Remote PowerShell Tunnel Design

## Goal
Connect a supported ChatGPT web custom MCP app to DeskTether on a local Windows machine so MCP calls can operate PowerShell sessions without exposing a local inbound port.

## Architecture

```text
ChatGPT Web custom MCP app
        |
        v
OpenAI Secure MCP Tunnel endpoint
        |
        | outbound HTTPS polling
        v
OpenAI tunnel-client v0.0.14 (Windows)
        |
        | stdio MCP
        v
DeskTether MCP Server
        |
        v
Policy + Audit + PowerShell Session Manager
        |
        v
powershell.exe
```

DeskTether stays a local stdio MCP server. We do not add a public HTTP listener because the official tunnel-client already forwards tunnel traffic to stdio MCP targets.
## V0.2 Scope

1. Add explicit MCP tools for PowerShell sessions:
   - `powershell_start`
   - `powershell_read`
   - `powershell_input`
   - `powershell_list`
   - `powershell_terminate`
2. Reuse the existing `ProcessSessionManager` so allowed-root checks, blocked-command checks, output buffering, and audit behavior remain centralized.
3. Add Windows tunnel bootstrap scripts that:
   - install the pinned official `tunnel-client` release;
   - verify the downloaded archive against the release SHA256 manifest;
   - build DeskTether before tunnel startup;
   - generate a local tunnel-client profile that launches DeskTether over stdio;
   - run `doctor` before starting the long-lived tunnel runtime.
4. Keep all runtime secrets in environment variables or tunnel-client profile secret references; never commit API keys.
5. Document the ChatGPT web setup steps and the account-plan limitation.

## Out of Scope

- Public HTTP ingress to DeskTether.
- Mouse, keyboard, screen, browser, or Windows UI automation.
- OAuth hosted by DeskTether.
- Automatic creation of OpenAI organization API keys.
- Circumventing ChatGPT plan or workspace permissions.
## Security Model

- `tunnel-client` makes outbound HTTPS requests to the OpenAI tunnel control plane; DeskTether does not bind a public listener.
- `DESKTETHER_ALLOWED_ROOTS` remains the filesystem and working-directory allowlist.
- `DESKTETHER_BLOCKED_COMMANDS` remains the command denylist.
- PowerShell tools are aliases over the same policy-enforced session manager, not a second unrestricted shell path.
- Every externally callable PowerShell action is recorded in the DeskTether JSONL audit log.
- OpenAI runtime/admin keys are never written to repository files, command-line arguments generated by DeskTether, or logs.
- The tunnel-client binary is pinned to v0.0.14 and its archive SHA256 is verified using the matching official `SHA256SUMS.txt` release asset.

## Local Configuration

Required for a live tunnel runtime:

- `CONTROL_PLANE_TUNNEL_ID`: OpenAI tunnel ID.
- `CONTROL_PLANE_API_KEY`: runtime API key with Tunnels Read + Use.
- `DESKTETHER_ALLOWED_ROOTS`: semicolon-separated Windows paths.
- `DESKTETHER_BLOCKED_COMMANDS`: semicolon-separated command prefixes.

Optional:

- `DESKTETHER_AUDIT_PATH`: explicit JSONL audit path.
- `TUNNEL_CLIENT_BIN`: path to an already installed tunnel-client executable.

## ChatGPT Product Boundary

As of 2026-09-17, ChatGPT does not directly connect to localhost MCP servers. Secure MCP Tunnel is the supported private-network bridge. Full custom MCP write/modify actions are currently available to Business, Enterprise, and Edu workspaces; the current Plus account cannot complete the final write-action attachment in chatgpt.com.
## Acceptance Criteria

- Existing V0.1 tools remain backward compatible.
- The MCP catalog exposes all five explicit PowerShell tools with unique names and Zod schemas.
- `powershell_start` executes through the existing policy-enforced session path and can be followed by read/input/list/terminate calls.
- A blocked command is rejected before process spawn and is surfaced as an MCP error.
- Tunnel bootstrap refuses to run when the runtime tunnel ID or API key is absent.
- Tunnel bootstrap uses the official v0.0.14 Windows amd64 release and verifies its SHA256 before extraction.
- The generated tunnel profile points to the compiled DeskTether stdio entrypoint and does not contain API keys.
- `tunnel-client doctor` can validate the local MCP binding once a valid OpenAI tunnel ID/runtime key are supplied.
- Repository tests, typecheck, build, and a compiled-server smoke test all pass.

## Delivery State

V0.2 is considered code-complete when the local machine is ready to attach through Secure MCP Tunnel. A live ChatGPT Web PowerShell call additionally requires an eligible ChatGPT workspace plus an OpenAI tunnel ID/runtime key; those are external account prerequisites rather than repository defects.
